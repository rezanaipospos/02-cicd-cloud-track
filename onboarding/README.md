# Onboarding — Prereq Pemula

**Prereq:** tidak ada (titik mulai).

## Tujuan
Membekali peserta tanpa pengalaman: dasar Linux/terminal, Git, Docker, pembuatan akun GCP, dan mindset DevOps.

## Langkah
1. Dasar Linux & terminal.
2. Git dasar (clone, branch, commit, push).
3. Docker dasar (build, run, image).
4. Buat akun GCP + aktifkan billing (panduan free-tier).
5. Pasang CLI: `gcloud`, `terraform`, `terragrunt`, `ansible`, `kubectl`.

## Verifikasi
- Checklist kesiapan lingkungan (FR-2): semua CLI terpasang & akun GCP aktif.

## Teardown
Tidak ada resource cloud di stage ini.
