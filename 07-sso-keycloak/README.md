# 07 — SSO (Keycloak)

**Prereq:** 05-gitops (cluster + GitOps).

## Tujuan
Integrasi Single Sign-On dengan Keycloak.

## Langkah
1. Install Keycloak.
2. Buat realm + client untuk aplikasi.
3. Lindungi aplikasi contoh dengan autentikasi SSO.

## Verifikasi
- Aplikasi memerlukan login SSO sebelum akses.

## Teardown
Dikelola via GitOps + cluster.
